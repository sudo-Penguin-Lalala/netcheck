03. Result Section Prominence

Add accent glow + slide-in animation when results appear

Before

> DNS Lookup Results

Query: example.com
Type: A
Answer: 93.184.216.34
TTL: 86400 
/* Original - no special treatment */
.result-panel {
  background: var(--card-bg);
  border: 1px solid var(--border);
  border-radius: 2px;
}

After

> DNS Lookup Results

Query: example.com
Type: A
Answer: 93.184.216.34
TTL: 86400 
/* Improved - accent glow + animation */
.result-panel {
  border-color: rgba(255, 180, 84, 0.2);
  box-shadow: 0 0 12px rgba(255, 180, 84, 0.08);
  animation: resultAppear 300ms ease-out;
}

@keyframes resultAppear {
  from {
    opacity: 0;
    transform: translateY(-8px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
✓ Results now draw attention with subtle glow + slide-in
