18. Skeleton Loading States

Replace spinners with content placeholders

Before

Loading...
/* Original - spinner only */
.spinner {
  border: 3px solid var(--border);
  border-top-color: var(--accent);
  animation: spin 0.8s linear infinite;
}

After

/* Improved - skeleton placeholders */
.skeleton {
  background: var(--border-strong);
  animation: pulse 1.5s ease-in-out infinite;
}

@keyframes pulse {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.5; }
}

/* Show content structure while loading */
.skeleton-title { height: 1.2rem; width: 60%; }
.skeleton-line { height: 0.9rem; width: 100%; }
✓ Content structure visible during load → better perceived performance
