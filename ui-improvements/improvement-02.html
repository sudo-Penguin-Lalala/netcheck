02. Tab Bar Separation

Add background + stronger border for better visual separation from content

Before

/* Original - tabs float on background */
.tabs {
  display: flex;
  gap: 0.25rem;
  flex-wrap: wrap;
}

After

/* Improved - contained tab bar */
.tabs {
  background: var(--card-bg); /* #11161e */
  border: 1px solid var(--border); /* #1c2532 */
  border-radius: 2px;
  padding: 0.5rem;
}
✓ Tab bar now has clear container, better visual hierarchy
