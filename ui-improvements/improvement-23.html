23. Reduced Motion Enhancements (WCAG 2.3.3)

Comprehensive motion reduction for accessibility

Before

Card with slide animation
/* Original - basic support */
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
  }
}
⚠ WCAG 2.3.3 (Level AAA) requires motion can be disabled by users. Basic implementation may miss some animations.

After

Card with no animation
/* Improved - comprehensive */
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }

  /* Disable spinner rotation */
  .spinner {
    animation: none;
    border-top-color: var(--border);
  }
}
✓ All animations disabled when user prefers reduced motion
