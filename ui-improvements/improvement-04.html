04. Button Hover Feedback

Stronger color shift + slight scale + shadow for better interactivity

Before

/* Original - simple opacity fade */
.btn {
  transition: opacity 150ms;
}

.btn:hover {
  opacity: 0.85;
}

After

/* Improved - color + scale + shadow */
.btn {
  transition: all 150ms ease-out;
}

.btn:hover {
  background: #ffc670; /* lighter shade */
  transform: translateY(-1px) scale(1.02);
  box-shadow: 0 2px 8px rgba(255, 180, 84, 0.3);
}

.btn:active {
  transform: translateY(0) scale(0.98);
}
✓ Buttons now feel more responsive and tactile
