15. Keyboard Shortcut Visual Hints

Show shortcuts on hover for better discoverability

Before

/* Original - no hints */
.action-btn {
  /* no tooltip */
}

After

/* Improved - tooltip on hover */
.action-btn:hover::after {
  content: attr(data-shortcut);
  position: absolute;
  bottom: calc(100% + 0.5rem);
  background: var(--card-bg);
  border: 1px solid var(--accent);
  color: var(--accent);
  animation: tooltipFade 150ms;
}

.action-btn:hover::before {
  /* arrow pointer */
  border-top-color: var(--accent);
}
