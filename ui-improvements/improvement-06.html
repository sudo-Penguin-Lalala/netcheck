06. Typography Scale Refinement

Use sans-serif for prose, monospace for data values

Before

> DNS Lookup

ok

Query resolved successfully. The domain example.com points to 93.184.216.34 with TTL of 86400 seconds.

/* Original - monospace everywhere */
body {
  font-family: "JetBrains Mono", monospace;
}

After

> DNS Lookup

ok

Query resolved successfully. The domain example.com points to 93.184.216.34 with TTL of 86400 seconds.

/* Improved - mixed typography */
body {
  font-family: -apple-system, sans-serif;
}

.data-value, code, pre {
  font-family: "JetBrains Mono", monospace;
}
✓ Prose more readable, data values stay monospace
